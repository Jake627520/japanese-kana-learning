# Contributing Guidelines

Thank you for your interest in contributing to Japanese Kana Learning!

## Development Setup

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the local development server:
   ```bash
   npm run dev
   ```

## Pre-Commit Verification

Before submitting a Pull Request, make sure to run:

```bash
npm run lint
npm run build
```

Both TypeScript linting and Vite build must complete without errors.

## Licensing & Asset Constraints

- Do NOT submit third-party copyrighted images, proprietary audio clips, or textbook materials.
- All submitted code must be compatible with the MIT License.
- Do not submit content copied from proprietary textbooks, paid courses, or copyrighted educational platforms without appropriate permission.
